# Slideshow hướng dẫn sử dụng Open Design

Slideshow tương tác tiếng Việt dành cho Designer, BA, PO và người review tài
liệu. Nội dung được biên tập từ
[`open-design-user-guide-vi.md`](../../guides/open-design-user-guide-vi.md).

## Mở slideshow

```bash
cd docs/slides/open-design-user-guide
npm run dev
```

Mở `http://localhost:3004`, sau đó:

- Dùng phím mũi tên trái/phải để chuyển slide.
- Nhấn `P` hoặc nút **Present** để mở màn hình dành cho người xem.
- Hai slide **Thiết lập** và **Chạy quy trình** có nhánh xử lý sự cố.
- Presenter view có ghi chú thuyết trình cho từng slide.

## Kiểm tra

```bash
npm run check
```

Slideshow gồm 14 slide chính và 2 slide nhánh hỗ trợ. Đây là deck tương tác,
không phải video render.
