Docker → Đăng nhập CLI → Quota.

Không bỏ qua lớp trước để xử lý lớp sau.

1. Docker
→

Mở Docker Desktop, chờ trạng thái running; nếu thiếu image, chạy lại Thiết lập thực thi.

2. CLI AI
→

Vào Cài đặt → Tài khoản CLI và đăng nhập Claude hoặc Codex.

3. Quota
→

Kiểm tra mức dùng, đổi runtime hoặc chờ thời điểm reset.

Dấu hiệu đã sẵn sàng
Docker OK · Image có sẵn · CLI báo signed in · Prompt thử nghiệm trả kết quả.
