# Icon set — Lucide (static, inline)

Static [Lucide](https://lucide.dev) SVG icons vendored for the
`html-interactive-prototype` skill. **Lucide is ISC-licensed** (permissive,
attribution): https://github.com/lucide-icons/lucide/blob/main/LICENSE

## How to use (self-contained, no CDN)
- Pick a name below, read `assets/icons/<name>.svg`, and **inline its `<svg>`** into the page.
- Each icon is `stroke="currentColor"` → it inherits the surrounding text `color`.
- Override `width`/`height` per context (see SKILL.md "Icons" for sizing). Keep ONE
  `stroke-width` across the whole set (Lucide default `2`; drop to `1.5`-`1.75` for a finer look).
- Do NOT `<link>`/`<img src>` these files in the output — inline only (the deliverable is self-contained).
- Need a glyph not here? Compose from an existing one or grab another Lucide name from lucide.dev — never hand-draw a new icon path.
